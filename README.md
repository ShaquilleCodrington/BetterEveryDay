# Better Every Day

> **Reduce the friction between ideas and action.**

Better Every Day is an offline-first desktop productivity platform designed to help you organize your work, capture ideas, stay focused, and continue making progress every day.

By bringing together notes, tasks, journeys, focus sessions, and productivity tools into one workspace, Better Every Day helps you spend less time managing your workflow and more time accomplishing what matters.

# Our Mission

Better Every Day exists to reduce the friction between ideas and action.

Whether you're planning tomorrow, writing notes during a meeting, completing daily habits, or tracking a long-term journey, the application should help you continue your work effortlessly.

Our long-term vision is a productivity platform that grows alongside its users—starting with a powerful desktop experience and expanding through continuity across devices, thoughtful collaboration, and tools that support both individuals and teams.

Every release is guided by one simple principle:

> **Make becoming better every day feel easier than it did yesterday.**

# Development

Install project dependencies:

```bash
npm install
```

Run the desktop development environment:

```bash
npm run dashboard
```

Create a production installer:

```bash
npm run installer
```

Publish a production release:

```bash
npm run installer:publish
```

# Vision

Better Every Day is more than a collection of productivity tools.

It is a platform built to help people organize their work, maintain focus, and continue making meaningful progress every day.

Every feature is evaluated using one guiding question:

> **Does this reduce friction and help people continue their work more naturally?**

If the answer is yes, it belongs in Better Every Day.

As the platform grows, our goal is to extend that experience through continuity across devices, thoughtful collaboration, and tools that support both individuals and teams—without losing the simplicity that makes productivity enjoyable.
